# AL HASM Premier Properties — Atelier Luxury v2

**هذه النسخة الجديدة بتصميم فاخر متحرك للواجهة الرئيسية ولوحة التحكم.** ابدأ بقراءة `WHATS_NEW_ATELIER_v2_AR.md` للتعديلات والتعليمات المختصرة.

**هذا المشروع يتضمن وضعين واضحين:**

## 1. معاينة تعمل فوراً بدون أي تثبيت

الطريقة المفضلة: افتح `START_INSTANT_PREVIEW.bat` ليعمل الموقع والداشبورد على عنوان localhost واحد، فتنعكس تغييرات المعاينة بين الصفحات. لا تحتاج هذه الطريقة PHP أو Composer؛ يكفي PowerShell الموجود في Windows. ويمكنك أيضاً فتح `OPEN_PREVIEW.bat` للموقع أو `OPEN_DASHBOARD.bat` للوحة التحكم مباشرة. أو افتح `preview/index.html` و`preview/dashboard.html` مباشرة من VS Code باستخدام **Open in Default Browser**. كل الروابط والنماذج وأزرار CRUD تعمل داخل المعاينة، وتُحفظ تغييراتك في **localStorage** الخاص بالمتصفح. يمكنك العودة إلى الصفحة الرئيسية ومن ثم استخدام «الإدارة» في أسفل الصفحة. المعاينة لا تحتاج PHP أو Composer أو Node.

> **المهم**: معاينة HTML مستقلة للتجربة فقط، وليست قاعدة البيانات الإنتاجية. إزالة بيانات المتصفح تمسح التغييرات داخل المعاينة.

## 2. تشغيل Laravel الحقيقي على الكمبيوتر (Windows)

المتطلبات: PHP 8.2 أو أحدث + ملحق `pdo_sqlite` وComposer. يمكن استخدام Laravel Herd على Windows لتوفير PHP وComposer. لا حاجة إلى npm؛ الـ CSS/JS جاهز مسبقاً.

بعد فك الضغط، شغّل `SETUP_AND_RUN_LARAVEL.bat`. عند التشغيل لأول مرة سيقوم بـ:

1. تنزيل مكتبات Laravel عن طريق Composer (إن لم تكن موجودة)، ويستلزم إنترنت.
2. إنشاء ملف `.env` ومفتاح تطبيق آمن.
3. تهيئة قاعدة بيانات SQLite وتشغيل migrations.
4. إضافة بيانات تجريبية إلى قاعدة البيانات **مرة واحدة فقط**.
5. إنشاء كلمة مرور مدير عشوائية محلية وتخزينها في `LOCAL_ACCESS_NOT_FOR_UPLOAD.txt`.
6. تشغيل السيرفر وفتح `http://127.0.0.1:8000` تلقائياً.

رابط الإدارة: `http://127.0.0.1:8000/admin/login`، والبيانات موجودة في الملف المحلي المذكور.

### تشغيل يدوي

```powershell
cd 'C:\PATH\TO\AL_HASM_Properties_Laravel12_Professional'
composer install
Copy-Item .env.example .env
New-Item database/database.sqlite -ItemType File -Force
# ضع ADMIN_EMAIL و ADMIN_PASSWORD (لا يقل عن 12 حرفاً) في .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

يمكن تغيير DB_CONNECTION إلى mysql وتعيين DB_HOST/DB_DATABASE/DB_USERNAME/DB_PASSWORD في `.env` عند النشر على cPanel، وتشغيل الأمر `php artisan migrate --force` هناك.

## الوظائف

- صفحات الموقع: الرئيسية، دليل العقارات مع بحث وفلترة، صفحات التفاصيل، المفضلة، المقارنة، من نحن، الخدمات، الاستفسار، التقييم، المدونة.
- اللغة العربية والإنجليزية واتجاه RTL/LTR متجاوب للجوال والكمبيوتر.
- لوحة التحكم: إحصائيات، عقارات CRUD، طلبات العملاء، مواعيد المعاينات، الصفقات، الفريق، المحتوى، إعدادات العلامة التجارية، وتصدير CSV.
- واجهات API عامة للعقارات والطلبات، وواجهات إدارة محمية بجلسة تسجيل دخول وكود CSRF، والتحقق من المدخلات، وحماية معدل إرسال الطلبات.
- الشعار الأصلي الذي قدمته مضمّن (مقتصّ من لقطة الشاشة لتحسين طريقة العرض).

## تنبيهات ما قبل النشر

- العقارات والأسعار وصور العقارات وأسماء العملاء والمقالات هي **أمثلة تخيلية** للتجربة، ليست عقارات فعلية.
- الصور الخارجية من Unsplash تحتاج اتصال إنترنت، وهناك صور SVG بديلة داخل المشروع عند تعذر التحميل.
- استبدل عنوان البريد `info@example.com` ببيانات الشركة الحقيقية من إعدادات الإدارة.
- لا ترفع `.env` أو `LOCAL_ACCESS_NOT_FOR_UPLOAD.txt` إلى موقع عام، واجعل `APP_DEBUG=false` و`APP_ENV=production` واضبط SSL.
- في الاستضافة ينبغي أن يكون Document Root هو المجلد `public` حصراً، وأن تكون مجلدات `storage` و`bootstrap/cache` قابلة للكتابة.
- حزمة ZIP تتضمن **مصدر Laravel وقاعدة فارغة**، لكن **مجلد `vendor` غير متضمن**، ويتم تثبيته من Composer في أول تشغيل. فتح ملف `.blade.php` منفرداً في المتصفح ليس طريقة تشغيل Laravel.
- ليس هناك ربط فعلي مع منصات إعلانات العقارات أو بوابات الدفع أو الخرائط أو واتساب؛ هذه تحتاج بيانات اتصال وحسابات خارجية وتكاملات.

**للمعاينة من داخل VS Code:** افتح المجلد ثم اضغط F5 واختر `Preview AL HASM Website`، أو افتح الملف `OPEN_ME_FIRST.html`. توجد مهمتان لفتح الموقع والداشبورد من Terminal > Run Task.
